# AcademicManagementSystem

## 📚 Academic Management System (Python)

This project is a Python-based application designed to simulate an academic management system through a command-line interface. It allows the management of entities such as students, teachers, subjects, classes, and enrollments.

The system implements basic CRUD operations (Create, Read, Update, Delete), enabling users to add, view, update, and delete records interactively. Data is persisted using JSON files, simulating a simple database structure.

This project was developed with a focus on practicing fundamental programming concepts, including data structures, functions, file handling, and logical code organization.

### 🚀 Features

* Register students, teachers, subjects, classes, and enrollments
* List stored records
* Update existing data
* Delete records
* Data persistence using JSON files

### 🛠️ Technologies Used

* Python
* JSON (data storage)
